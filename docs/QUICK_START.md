# 黑马记账 - 快速入门指南

## 🚀 30秒快速开始

### 1. 启动应用

```bash
npm run dev
```

应用将在浏览器中打开：`http://127.0.0.1:5173/`

### 2. 记录第一笔

1. 点击顶部的"记一笔"按钮
2. 输入金额：`35.50`
3. 选择日期：默认是今天
4. 选择分类：点击"餐饮美食" → "午餐"
5. 点击"保存记录"

### 3. 查看统计

- 点击顶部导航的"统计"查看支出趋势
- 点击"数据管理"导出数据

## ⚙️ 常用操作

### 📝 添加记录

1. 点击"记一笔"
2. 输入金额和选择分类
3. 添加备注（可选）
4. 上传图片（可选）
5. 保存

### 📊 查看统计

1. 点击顶部导航的"统计"按钮
2. 选择时间范围：今日/本周/本月/本年/自定义
3. 查看图表和排名
4. 导出数据

### 📁 管理分类

1. 点击"分类管理"
2. 查看系统分类和自定义分类
3. 添加新分类
4. 编辑或删除分类

### 💾 备份数据

1. 点击"数据管理"
2. 选择"数据备份"
3. 点击"备份数据"
4. 查看备份文件夹

### 🔄 恢复数据

1. 点击"数据管理"
2. 选择"数据恢复"
3. 选择备份文件
4. 确认恢复

## 💡 使用技巧

### 快速搜索

在搜索框输入：
- `35` - 搜索金额为35的记录
- `午餐` - 搜索分类为"午餐"的记录
- `备注内容` - 搜索备注中的文字
- `2026-09` - 搜索日期

### 分类筛选

- 点击某个分类标签进行筛选
- 再次点击取消筛选
- 使用"重置"按钮清除所有筛选

### 预算设置

1. 进入"统计"页面
2. 查看"月度预算"卡片
3. 输入月度预算金额
4. 应用会自动计算剩余预算和提醒

### 图片附件

- 记录时可以上传消费凭证
- 支持JPG、PNG格式
- 最大5MB
- 可预览和删除

## 🔧 高级功能

### 导出格式

- **JSON**：完整数据，保留所有信息
- **CSV**：表格格式，可用Excel打开
- **Excel**：带格式和样式的Excel文件

### 数据清理

- **重复记录**：查找并删除完全相同的记录
- **空记录**：删除金额为0或空白的记录
- **旧数据**：删除指定日期之前的记录

### 自定义分类

- **一级分类**：独立的分类项
- **二级分类**：作为一级分类的子项
- **图标选择**：20+种表情图标可选
- **颜色标识**：自定义分类颜色

## ❓ 常见问题

### Q: 支持删除记录吗？
A: 支持，在记录列表中点击记录可以进入编辑页面，点击删除按钮。

### Q: 如何修改记录？
A: 点击记录项进入编辑页面，修改后保存即可。

### Q: 预算设置后如何查看？
A: 在主页底部的"本月预算"卡片可以看到剩余预算和进度条。

### Q: 数据保存在哪里？
A: 所有数据保存在应用的数据目录中，备份文件在`backups`文件夹。

### Q: 可以在多个设备使用吗？
A: 可以，通过导出导入功能在设备间迁移数据。

### Q: 图片会占用很多空间吗？
A: 图片以base64格式存储，较大图片会增加数据文件大小。
