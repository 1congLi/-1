# 黑马记账 - 用户使用指南

## 快速开始

### 1. 启动应用

```bash
# 开发模式启动
npm run dev

# 或者直接运行开发脚本
node dev.js
```

应用将在 `http://127.0.0.1:5173` 启动

### 2. 第一次使用

首次打开应用时，会自动加载系统预设的10个一级分类和80个二级分类。

### 3. 记录花销

1. 点击顶部导航栏的"记一笔"按钮
2. 输入金额（支持小数点）
3. 选择日期（默认当天）
4. 选择分类（支持2级分类选择）
5. 添加备注（可选）
6. 上传消费凭证图片（可选）
7. 点击"保存记录"

## 功能说明

### 🏠 主界面

#### 视图切换
- **今日**：查看今天的消费记录
- **本周**：查看本周的消费记录
- **本月**：查看本月的消费记录
- **全部**：查看所有消费记录

#### 搜索功能
在搜索框中输入关键词，可以搜索：
- 金额
- 分类名称
- 备注
- 日期

#### 分类筛选
点击分类标签可以筛选指定分类的记录。再次点击取消筛选。

#### 底部统计
显示当前视图的总支出金额和记录笔数。

### ✏️ 记录花销

#### 金额输入
- 支持输入任意金额（如：35.50）
- 精确到小数点后两位
- 默认0.00

#### 分类选择
- 点击一级分类展开二级子分类
- 点击二级分类完成选择
- 支持系统预设分类和用户自定义分类

#### 图片附件
- 支持上传消费凭证图片（JPG、PNG格式）
- 图片大小限制：5MB以内
- 可预览和删除上传的图片

### 📊 统计分析

#### 统计维度
- **总支出**：当前时间范围内的总花费
- **日均支出**：平均每天的支出金额
- **最大单笔**：单笔最大支出及对应的分类
- **月度预算**：本月预算使用情况

#### 图表展示
- **支出趋势图**：折线图或柱状图，展示消费趋势
- **分类占比图**：饼图展示各分类支出占比

#### 分类排行
- 按金额、笔数、名称排序
- 显示每个分类的支出金额、占比、笔数、平均金额

#### 自定义时间范围
- 支持：今日、本周、本月、本年、自定义
- 自定义时间范围可以选择开始和结束日期

### 📁 分类管理

#### 分类体系
- **一级分类**：系统预设的10个大类
  1. 餐饮美食
  2. 交通出行
  3. 购物消费
  4. 休闲娱乐
  5. 居住缴费
  6. 医疗健康
  7. 教育学习
  8. 人情往来
  9. 工作相关
  10. 其他支出

- **二级分类**：每个一级分类下的细分类别（共80个）

#### 自定义分类
- **添加分类**：点击"分类管理" → "添加分类"
- **添加一级分类**：选择类型为"一级分类"
- **添加二级分类**：选择类型为"二级分类"，并选择父分类
- **编辑分类**：修改分类名称、图标、颜色
- **删除分类**：删除未被使用的分类

#### 图标选择
支持的表情图标：
🍔 🚗 ☕ 🎮 💰 📱 🛒 🎨 🎵 ⚽ 🎬 ✈️ 🏠 💼 🎁 💡 🔥 ❤️ ⭐ 🌟

### 🗂️ 数据管理

#### 数据备份
- **备份到本地**：点击"数据备份" → "备份数据"
- **查看备份**：点击"查看备份"打开备份文件夹
- 备份文件保存在应用数据目录的 `backups` 文件夹中
- 备份文件命名格式：`backup-2026-09-02T12-00-00-000Z.json`

#### 数据恢复
- **选择备份文件**：点击"数据恢复" → "选择备份文件"
- **确认恢复**：恢复前会显示确认对话框
- **恢复效果**：会覆盖当前所有数据

#### 导出数据
支持导出以下格式：
- **JSON**：完整数据格式，可用于导入
- **CSV**：表格格式，可导入Excel
- **Excel**：带样式的Excel文件

#### 导入数据
- **选择JSON文件**：点击"导入数据" → "选择JSON文件"
- **确认导入**：导入前会显示确认对话框
- **导入效果**：合并到现有数据中

#### 数据清理
- **清理重复记录**：删除完全相同的重复记录
- **清理空记录**：删除金额为0或空白的记录
- **清理旧数据**：删除指定日期之前的记录

## 预算管理

### 设置月度预算
点击统计界面的"月度预算"卡片，输入月度预算金额。

### 预算提醒
应用会自动提醒：
- **超支警告**：支出超过100%时显示红色警告
- **接近预算**：支出达到90%时显示橙色提醒
- **日预算监控**：当日支出达到预算的1.5倍时提醒

## 常见问题

### Q: 如何恢复误删的记录？
A: 暂不支持恢复已删除的记录，请定期备份数据。

### Q: 支持云同步吗？
A: 当前版本不支持云同步，所有数据存储在本地。

### Q: 如何修改系统预设分类？
A: 系统预设分类是只读的，只能添加用户自定义分类。

### Q: 图片附件能保存多久？
A: 图片以base64格式保存在数据文件中，无大小限制（建议5MB以内）。

### Q: 数据可以共享吗？
A: 可以通过导出导入功能在设备间迁移数据，但当前版本不支持直接共享。
